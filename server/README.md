# ChatHNS Server

Backend WebSocket server for ChatHNS.

## HNSChat → ChatHNS

ChatHNS is based on HNSChat, originally created by [eskimo](https://github.com/hnschat/).

ChatHNS is maintained and extensively developed by [Danyelo Dolce](https://github.com/danyelo73).

Original project:
https://github.com/hnschat/

Original server source:
https://github.com/hnschat/server

ChatHNS contains extensive modifications and additional functionality.
