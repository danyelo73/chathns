ChatHNS PUBLIC SOURCE RELEASE
=============================

This repository contains the public source release of ChatHNS.

ChatHNS is actively developed and the live service contains infrastructure
and configuration that are intentionally not included in this repository.

This repository is therefore not a ready-to-deploy copy of the production
server.

IMPORTANT
---------

- Production credentials and secrets are not included.
- Production configuration is not included.
- Runtime data, accounts, sessions and ALF tickets are not included.
- Public HNS ownership verification requires external infrastructure.
- ALF verification requires separate configuration and services.
- Janus/video requires separate configuration.
- Push services require separate configuration.
- Third-party API services require their own credentials.
- Production TLS/WSS/reverse-proxy configuration is not included.
- Some legacy HNSChat code remains while ChatHNS development continues.

The included local configuration samples are intended for development and
inspection of the source.

See INSTALL.md for local setup information.
See SOURCE_NOTES.md for additional implementation notes.
